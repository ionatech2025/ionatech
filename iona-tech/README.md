🏫 Iona Institute of Technology — Official Website

This project is the official website of the Iona Institute of Technology (IIT), built with React and Vite for blazing-fast performance and modern development experience. It includes responsive UI components, smooth scrolling, and optimized builds powered by Tailwind CSS and Lucide Icons.

🚀 Tech Stack
Category	Tools & Libraries
Frontend Framework	React

Build Tool	Vite

Styling	Tailwind CSS
 + Autoprefixer

Icons	Lucide React

Scrolling Effects	React Scroll

Linting	ESLint
 with React plugin support
📦 Project Setup
1️⃣ Clone the Repository
git clone https://github.com/your-username/iona.git
cd iona

2️⃣ Install Dependencies
npm install

3️⃣ Run Development Server
npm run dev


Your site will be available at: http://localhost:5173

4️⃣ Build for Production
npm run build

5️⃣ Preview the Production Build
npm run preview
